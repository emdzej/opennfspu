# Controls

The game will read the keyboard directly, with the original's default keys, and gamepads through gasm's
virtual pads. The tables come with the frontend and the driving code; nothing is mapped yet.

gasm's own keys work in every runner: in `gasm-run`'s window, <kbd>F11</kbd> (or <kbd>Alt</kbd> +
<kbd>Enter</kbd>, or <kbd>Ctrl</kbd> + <kbd>Cmd</kbd> + <kbd>F</kbd> on macOS) switches fullscreen, and
holding <kbd>Esc</kbd> for a second quits.
