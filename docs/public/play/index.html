Porsche Unleashed in your browser

OpenNFSPU runs here as opennfspu.wasm on the gasm runtime: the same module as on the desktop, a port of the original game's code, reading the cars, tracks, sounds and music from your own copy of Need for Speed: Porsche Unleashed. Nothing from the game is on this site, and nothing you pick leaves your computer.

Single player is playable: Quick Race, the knockouts, the Evolution career and Factory Driver, from the menus to the races and back. Multiplayer is in progress: games through a gasm relay (Network games). See Status.

What you need

  • Need for Speed: Porsche Unleashed for Windows, installed and updated to version 3.5: the folder with GameData, FEData and Porsche.exe, or an .iso image of it. See Game data.
  • A browser with WebAssembly, Web Workers, WebGL 2 and OffscreenCanvas: a recent Chrome, Edge, Firefox, or Safari 17 and later.
  • About 520 MB of browser storage to import the data (once; later visits start at once), or none to play without importing.
  • A keyboard, or a gamepad.

The installed game, for example C:\Program Files (x86)\EA GAMES\Need For Speed - Porsche Unleashed, or an .iso image of that folder (how to make one). The setup disc itself won't do: install the game first.

    Importing copies the files the game reads into this site's private browser storage (OPFS). Playing without importing reads them from the folder you picked, which you'll need to pick again next time.

    Controls

    The menus use the mouse. The game reads the keyboard directly, with the original's default keys (the arrow keys drive), and gamepads; Options › Controls changes them. Esc in a race opens the pause menu. More in Controls.

    Holding Esc for a second stops the game. In fullscreen the browser takes Esc to leave fullscreen. Profiles and options are kept in this browser.
